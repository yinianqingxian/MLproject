## 2. 实验一：CLAHE 相对原图

同增强、同种子逐种子配对，单位百分点（Macro-F1）。

| 增强 | 干净 | 模糊中 | 噪声中 | 变暗中 | JPEG中 | 12 干扰条件均值 |
|---|---|---|---|---|---|---|
| repeat_clean | +1.58 | +6.70 | +8.94 | +1.17 | **+14.43** | 73.36 → **80.41（+7.05）** |
| targeted_motion | +0.79 | +1.56 | +7.62 | +9.81 | +6.66 | 75.31 → **82.07（+6.76）** |
| mixed | +0.72 | +0.46 | **−0.77** | +2.72 | +3.15 | 83.07 → **85.41（+2.34）** |

**结论：CLAHE 有稳定帮助，但边际收益随训练增强递减。** 无干扰重复采样基线上 +7.05；混合增强上只剩 +2.34，中强度噪声甚至 −0.77。
可解释为 CLAHE 与"训练时见过多种干扰"部分重叠，二者同时使用是次可加的。

## 3. 实验二：去噪 CLAHE 相对直接 CLAHE（均取 mixed）

| 条件 | 差值 | 同向种子 |
|---|---|---|
| 干净 | +0.99 ± 0.65 | 3/3 |
| 模糊 低/中/高 | +1.44 / +2.69 / +1.40 | 2/3、2/3、2/3 |
| 噪声 低/中/高 | +1.52 / +2.62 / **+3.31** | 3/3、2/3、2/3 |
| 变暗 低/中/高 | +1.49 / +1.00 / +0.27 | 3/3、2/3、1/3 |
| JPEG 低/中/高 | +2.99 / **+3.88** / +3.90 | 2/3、3/3、2/3 |
| **12 干扰条件均值** | 85.41 → **87.61（+2.20）** | — |
| **最差条件** | 56.79 → **60.70** | — |

**结论：双边滤波在十三条件上全部为正，且干净图没有付出代价。** 噪声高强度 +3.31、JPEG 中强度 +3.88 是最大收益；
连干净图都 +0.99（3/3 同向），说明收益不只来自降噪，可能还有平滑带来的正则化效应。
"双边滤波会抹掉 32×32 上的数字笔画"这一担心在本规模没有出现。
