# A 十三条件评估协议 v1

2026-11-17，经用户授权补齐。此文件取代 A_START_STATUS 和 A_LINUX_STEPS 中“等待参数表”的状态及未采用草案。方案在正式结果产生之前确定，不根据测试集选强度。它是本项目的合成干扰协议，不声称是标准 GTSRB-C 基准或 ResNet 原论文协议。

| 干扰 | 低强度 | 中强度 | 高强度 |
|---|---|---|---|
| 运动模糊 | 核大小 3 | 5 | 7 |
| 高斯噪声 | 标准差 10 | 20 | 30 |
| 变暗 | 乘数 0.70 | 0.45 | 0.25 |
| JPEG 压缩 | 质量 40 | 20 | 10 |

另外包含 clean/none，共十三个条件。噪声标准差基于 0–255 像素范围。模糊是归一化水平/竖直线核，按冻结清单行号交替方向；所有强度方向相同。JPEG 用 OpenCV 编码后解码，亮度和噪声截断到 0–255 后转 uint8。

所有图像先按公共代码缩放到 32×32，再施加单种干扰，再生成 RGB、CLAHE 或去噪 CLAHE 视图，最后由公共 ResNet 执行官方 224 输入变换。没有干扰叠加、训练更新或重新选验证图。每条件使用相同 840 张开发集图像，共 10,920 个图像–条件对。

四个 medium 和 clean 直接复用 `prepare_data` 的像素，确保与原五条件可比。新增 low/high 噪声按固定种子 20261117 与文件相对路径的 SHA256 派生独立随机状态，两档共享标准正态噪声场；medium 保留旧随机流，因此三个强度并非共享同一个噪声场。跨强度的单图差异不应完全解释为强度的因果效应。所有模型、训练种子必须复用同一条件指纹。

## Linux 使用

正式九次训练完成并通过核验后：

```bash
bash A_LINUX.sh eval13
```

默认读取 `results/a_resnet18_linux_v1/`，写入新目录 `results/a_eval13_linux_v1/`。也可指定：

```bash
A_OUTPUT=results/a_resnet18_linux_v2 A_EVAL_OUTPUT=results/a_eval13_linux_v2 bash A_LINUX.sh eval13
```

同一评估入口支持 B/C 的公共 ResNet 研究目录：

```bash
python experiments/evaluate_a13.py --study results/你的研究目录 --output results/新的评估目录 --device cuda
```

不修改公共训练源码和已有训练产物。每个模型加载最终权重，输出十三条 Macro-F1/accuracy、10,920 条逐图预测、十三份特征文件和成本表。A 的九个模型合计 117 条指标、98,280 条预测、117 份特征。输出目录存在时拒绝覆盖，中断后选择新目录重跑评估。评估结束生成 `completion.json`，记录模型和输出文件指纹。

`conditions.json` 记录参数、像素指纹、划分和源码指纹；`images.csv` 记录图像与轨迹。`costs.csv` 的 preprocessing_seconds 是公共三视图缓存构建时间，所有模式都生成三视图，不能作为各模式独立部署成本。evaluation_seconds 在每条件预热 128 张后计时，包含 CPU→GPU、官方输入变换、网络推理及特征/预测回传，不包含磁盘写入、干扰生成或三视图缓存构建；它是评估吞吐成本，不是纯网络延迟。每条件测一次，不能据此作微小速度差异的显著性结论。时间比较应使用同一设备、软件环境、batch 和负载。

当前入口只评估开发集。官方测试入口、方法冻结及最终独立测试仍为后续任务。新增强度无需重新训练；不得用官方测试结果修改强度。
