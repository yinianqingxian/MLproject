# C 官方 ResNet18 双视图融合训练协议

本协议说明用户确认的新范围：保留原定双视图融合与消融，只将共享骨干替换为 torchvision 官方 ResNet18。模型结构与 ImageNet 权重使用官方版本，训练优化器和增强对照沿用本项目协议，不声称复现论文的 ImageNet 训练。官方测试在全组方案冻结后才使用。新 ResNet 正式结果须在 Spark 重新运行，历史 SmallCNN 分数不属于本模型。

## 数据与公平控制

类别顺序为 1、2、3、4、5、7、8。`results/pilot_split.csv` 来自官方训练集，含 2,940 张训练图（98 条轨迹）与 840 张开发验证图（28 条轨迹），每轨迹 30 帧，类别包含在轨迹 ID 中。训练与验证没有轨迹交叉。完整 43 类数据随包保留，用于完整性检查及后续独立测试，不扩大本次训练范围。

每次训练保留全部 2,940 张原图，增加相同来源索引的 1,470 个条目，总计 4,410。`repeat_clean` 重复原图；`targeted_motion` 添加模糊；`mixed` 中模糊、噪声和变暗各 490。程序先重放固定划分的 RNG，再按原预实验顺序生成干扰，不能重新抽样替换冻结划分。

## 模型与训练

输入先缩放到 32×32，再施加干扰并生成两种配对视图。CLAHE 仅处理 LAB 的 L 通道，clip limit 2.0、网格 4×4；去噪版本先做双边滤波 `d=5,sigmaColor=25,sigmaSpace=2`。原 BGR 数据不变，网络输入为 RGB、浮点范围 0–1。

共享骨干直接使用官方 `torchvision.models.resnet18`，加载 `ResNet18_Weights.IMAGENET1K_V1`，保留其 stem、BatchNorm、残差层、下采样和平均池化。平均池化后为 512 维表示，分类头适配七类，不增加自定义残差块、注意力或投影层。对上述缓存的 32×32 视图逐批应用官方 Resize256、CenterCrop224 和 ImageNet 归一化，骨干实际输入为 224×224。

保留原学习标量门控，初始化为 0.5，融合为 `(1-g)*z_raw + g*z_enhanced`。固定平均模型从相同官方预训练骨干初始化后独立微调，始终 g=0.5。全部骨干参数参与微调；此处的从头训练固定融合指独立优化固定融合模型，不表示放弃 ImageNet 初始化。官方权重及完整指纹见 `assets/weights/README.md`。

统一使用 AdamW，学习率 0.003、weight decay 0.01、betas=(0.9,0.999)、epsilon=1e-8、batch 128、10 轮，种子 42/43/44；每次 350 次优化更新。只评价最后一轮，不按最佳验证轮挑选成绩，不启用混合精度或 `torch.compile`。

## C 的 15 次实验

| 增强 | 输入 | 种子数 | 训练次数 |
| --- | --- | --- | --- |
| repeat_clean、targeted_motion、mixed | raw+CLAHE 学习门控 `dual` | 各 3 | 9 |
| mixed | 从头训练的固定平均 `fixed` | 3 | 3 |
| mixed | raw+去噪 CLAHE 学习门控 `dual_denoised` | 3 | 3 |

五种开发条件为 clean、motion（核 5、方向交替）、noise（sigma 20）、dark（gain 0.45）、jpeg（quality 20）。同一学习门控模型额外固定 g=0/0.5/1 做推理干预；这些端点不是独立训练的单分支。

## 产物和证据边界

每次运行保存最终权重、冻结配置、十轮日志、五条指标、4,200 条常规验证预测，以及干净训练和五种验证条件共六份对齐的 512 维特征。特征按图像名排序，附真实类别、预测、轨迹和门控。学习门控模型还保存 15 条干预指标和 12,600 条干预预测。全部运行完成后应有 75 条常规指标、63,000 条常规预测、90 份特征、180 条干预指标和 151,200 条干预预测。这是验收数量，不代表打包时已生成正式 ResNet 成绩。

报告汇总三个种子的均值、样本标准差和配对差值，区分训练固定平均与推理固定门控。帧与同轨迹图像相关，不能把逐图行数当作独立实验次数。Spark 与 Windows 环境分开记录和报告，不混合均值，也不预设新方法必须涨分。

正式 raw/CLAHE 单分支对照、特征聚类、多强度和官方测试属于全组后续工作。历史 SmallCNN 模型、计时和分数独立保留。本包的新 ResNet18 结果必须标注官方预训练与输入适配，不能把旧结论改名，也不能把差值全部归因于残差结构。
